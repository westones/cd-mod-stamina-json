# Stamina Presets — Crimson Desert v1.05.01

Updated port of [Infinite Stamina](https://www.nexusmods.com/crimsondesert/mods/107) by **PhorgeForge**. All credits to him ❤️

## Presets
- `infinite` — 0% stamina cost
- `10pct` — 10% stamina cost
- `25pct` — 25% stamina cost
- `50pct` — 50% stamina cost
- `75pct` — 75% stamina cost

## Covers
Sprint, flight, horse (herspia), climbing, grappling, Axiom Force, aerial, swim, combat, guard, wrestle, bow, vehicle.

## Requirements
[JSON Mod Manager](https://www.nexusmods.com/crimsondesert/mods/113)

## Usage
Drop the desired `.json` into JSON Mod Manager or CDUMM and apply.
